Project Overview

This application evaluates an existing web checkout interface using Jakob Nielsen’s 10 Usability Heuristics, identifies key WCAG 2.1 accessibility violations, and delivers an interactive 'Before vs. After' redesign suite.

Cataloged Interaction Paths

  • Path A (Browse & Filter): Search query input -> Live list update or empty state fallback.
  • Path B (Product Selection): View item details -> Select color/spec -> Proceed to payment.
  • Path C (Form Submission): Real-time regex validation -> Character counter update -> Submission.

Interaction Design Rationale

Transitions leverage natural spring physics curves, avoiding layout jumps. Critical feedback loops ensure visibility of system status (Heuristic #1) while error recovery states allow easy fix paths (Heuristic #9).
